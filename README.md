# 宋元明清闖關島

國中歷史（三）第 3–4 章（宋元、明清）的 3D 闖關複習遊戲。10 座島、62 格，一次走一格，答對就在島上蓋出模型；整座島答完再通過關卡門（3 題答對 2 題），橋才會放下。

**開始玩：** https://garfieldhuang.github.io/history-island/

- 單一檔案 `index.html`，Three.js 0.160.0 從 jsDelivr 載入，不需要建置。
- 題目都在 `index.html` 最上面的 `DATA` 物件裡，改那裡就好。
- 進度存在玩家自己的瀏覽器（localStorage）。

## 排行榜（Google 試算表）

GitHub Pages 只能放靜態檔，所以分數存在一份 Google 試算表裡：

1. 開一份新的 Google 試算表 → **擴充功能 → Apps Script**（直接在 script.google.com 建也可以，第一次執行會自動建一份「宋元明清闖關島排行榜」試算表；在編輯器執行 `showSheetUrl` 可在執行記錄看到它的網址）。
2. 把 [`apps-script/Code.gs`](apps-script/Code.gs) 整份貼上、存檔。
3. **部署 → 新增部署作業** → 類型選「網頁應用程式」→ 執行身分「我」→ 存取權「所有人」→ 部署（第一次要授權）。
4. 複製結尾是 `/exec` 的網址，填進 `index.html` 的 `DATA.meta.leaderboard`。
5. 之後改了程式碼要更新：**部署 → 管理部署作業 → 鉛筆圖示 → 版本選「新版本」→ 部署**，網址不會變。

排名規則：先比過關島數，再比星星，再比第一次就答對的比例。每台裝置有自己的玩家 id，同一個人重玩只會保留最好的成績。想刪掉亂取的名字，直接在試算表刪那一列。
